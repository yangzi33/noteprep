# U3:生成进度页(`/jobs/[id]`)按 Figma 重排 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 `/jobs/[id]` 的状态面板改成 Figma 的"生成中"卡片(四步进度列表、取消入口、失败/取消/完成的提示),轮询、取消、成功后重定向的现有行为一字不改。

**Architecture:** 纯前端。新增纯函数 `src/lib/ui/job-steps.ts`(状态+阶段 → 四步列表与标题);把 `JobStatus` 拆成"有状态的外壳"(轮询、`router.refresh`,保持不变)和"纯展示的 `JobStatusView`"(可用 `renderToStaticMarkup` 测试);取消操作作为 prop 传入展示组件。

**Tech Stack:** Next.js 16、React 19、Tailwind 4、lucide-react、Vitest、Playwright。

**Spec:** `docs/superpowers/plans/2026-10-20-figma-ui-implementation.md`(§0、§4.2 "Supporting · Generation stages"、§6 U3);U1/U2 计划里的组件契约;Figma 状态画板 `49:14344`(生成中)、`58:599`/`53:*`(失败/错误类)。

### Task 1: 步骤与标题的纯函数

**Files:**
- Create: `src/lib/ui/job-steps.ts`
- Test: `tests/unit/job-steps.test.ts`

**Interfaces:**
- Consumes: `JobView` from `@/lib/ui/job-view`(只用 `state`、`stage`、`attempt`)。
- Produces:
  - `type StepState = "done" | "active" | "todo" | "failed"`
  - `interface JobStep { id: "checked" | "writing" | "building" | "preview"; label: string; state: StepState }`
  - `jobSteps(job: Pick<JobView, "state" | "stage">): JobStep[]` — 固定 4 项,标签依次为 `Curriculum and settings checked`、`Writing and checking the lesson`、`Building your PDFs`、`Preparing the preview`。`generating` 与 `validating` 阶段都映射到第 2 步,`compiling` → 第 3 步,`storing` → 第 4 步。规则:第 1 步在作业存在时恒为 `done`;`queued` → 其余 `todo`;`running` + 阶段 s:s 之前的步骤 `done`,s 所在步骤 `active`,之后 `todo`;`running` 且 `stage === null` → 第 2 步 `active`;`succeeded` → 全部 `done`;`failed` 且 `stage` 非空 → s 之前 `done`、s 所在步骤 `failed`、之后 `todo`;`failed` 且 `stage === null` → 第 1 步 `done`,其余 `todo`;`canceled` → s 之前(及不含 s)的步骤 `done`,s 所在步骤和之后 `todo`(`stage === null` 时只有第 1 步 `done`)。
  - `jobHeading(job: Pick<JobView, "state" | "attempt">): string` — `queued`/`running` → `Preparing your lesson pack.`;`succeeded` → `Your lesson pack is ready.`;`failed` → `We could not finish this lesson pack.`;`canceled` → `Generation canceled.`。
  - `jobOverline(job: Pick<JobView, "state" | "attempt">): string` — `MATERIAL CREATION · ` 加上大写状态词:`queued` 且 `attempt > 0` → `WAITING TO RETRY`;`queued` → `QUEUED`;`running` → `GENERATING`;`succeeded` → `COMPLETE`;`failed` → `FAILED`;`canceled` → `CANCELED`。
  - `stepStateText(state: StepState): string` — `done`→`Done`、`active`→`In progress`、`todo`→`Not started`、`failed`→`Failed`(给屏幕阅读器用)。

### Task 2: `JobStatusView` 展示组件 + `JobStatus` 外壳 + 页面

**Files:**
- Create: `src/components/job-status-view.tsx`
- Modify: `src/components/job-status.tsx`、`src/app/jobs/[id]/page.tsx`
- Test: `tests/unit/job-status-view.test.ts`

**Interfaces:**
- Consumes: Task 1 的 `jobSteps`、`jobHeading`、`jobOverline`、`stepStateText`;`JobView`、`isRetrying`、`isTerminal` from `@/lib/ui/job-view`;`describeOutcome`、`stateLabel` from `@/lib/ui/messages`;`succeededPanel` from `@/lib/ui/lesson-view`;U1 的 `Card`、`Notice`、`Button`;`lucide-react` 图标(`CircleCheck`、`LoaderCircle`、`Circle`、`CircleAlert`)。
- Produces:
  - `JobStatusView({ job, offline, panel, cancelAction }: { job: JobView; offline: boolean; panel: { href: string | null; text: string }; cancelAction: (formData: FormData) => void | Promise<void> }): JSX.Element` — **无状态、无 hooks、无 `"use client"`**。结构:`<section aria-live="polite" data-testid="job-status" data-state={job.state}>`(`Card` 样式)里依次:
    1. `jobOverline(job)`(小号大写字,`text-text-accent`);`<h1>` 用 `font-heading` 显示 `jobHeading(job)`;
    2. `<p data-testid="job-state">`:`isRetrying(job) ? "Waiting to retry" : stateLabel(job.state)`(**沿用现有逻辑与文字**);非终态且 `attempt > 1` 时再显示 `Attempt {attempt} of {maxAttempts}`;`cancelRequested` 且非终态时显示 `Cancel requested…`;
    3. `<ol aria-label="Generation steps">`:`jobSteps(job)` 每项一个 `<li>`,图标(`done`→`CircleCheck`、`active`→`LoaderCircle`+`animate-spin`、`todo`→`Circle`、`failed`→`CircleAlert`,均 `aria-hidden`)+ 标签文字 + `<span className="sr-only">` 放 `stepStateText`;
    4. 结果提示:`describeOutcome(job.state, job.errorCode)` 非空时 → `<Notice intent={job.state === "failed" ? "error" : "info"}>`;`succeeded` → `<Notice intent="success" data-testid="job-succeeded">`,内容为 `panel.text`,且 `panel.href` 非空时跟一个 `<Link href>`,文字精确为 `Open the preview`;
    5. `offline` 时 `<p className="text-sm text-muted-foreground">Connection problem; still trying…</p>`;
    6. 非终态且未 `cancelRequested`:`<form action={cancelAction}>`,含 `<input type="hidden" name="jobId" value={job.id}>` 和一个 `<Button type="submit" variant="link">Cancel generation</Button>`;终态显示两个链接 `My materials`(`/lessons`)与 `Create another`(`/prepare`);
    7. 非终态时的说明:`Your progress is saved. You can leave this page and find your lesson in My materials.`
  - `JobStatus({ initial, hasPreview })`(`"use client"`,**逻辑原样保留**:`useState`、两个 `useEffect`、`fetch(/api/jobs/…)` 轮询、`router.refresh()`、`offline`、`panel = succeededPanel(...)`):只把渲染换成 `<JobStatusView job={job} offline={offline} panel={panel} cancelAction={cancelJobAction} />`。
