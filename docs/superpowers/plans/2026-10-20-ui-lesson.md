# U4:课包页(`/lessons/[id]`)+ HTML 草稿预览 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把课包页改成 Figma 的编辑器外观(标题 + 版本徽章、复核提示、文档标签、预览区、右侧"导出"与"课程"卡片),并按 D-60 增加由同一份结构化内容渲染的 **HTML 草稿预览**;编译出的 PDF 预览、下载、同一 `revisionId` 规则全部保持不变,PDF 仍是默认视图。

**Architecture:** 新增只读 DAL 方法取回本人、已定稿修订的**已校验课包**(`PackageSchema`);纯函数 `src/lib/package/html-view.ts` 把课包的某份文档变成一棵类型化的 HTML 视图树(文字、列表、题目、带内联数学的片段,数学 TeX 串复用 `src/lib/latex/math.ts`,不重新解释数学);服务端组件把这棵树渲染成 React 元素(文字由 React 转义),数学经 KaTeX(`trust:false`、严格模式)渲染。页面用 `?view=draft` 切换,缺省仍是 PDF。

**Tech Stack:** Next.js 16、React 19、Tailwind 4、`katex`(新依赖,D-60 已批准,精确版本)、Vitest、Playwright。

**Spec:** `docs/superpowers/plans/2026-10-20-figma-ui-implementation.md`(§0 决定 D-58–D-64、§4.2、U4);`CLAUDE.md` §7(PDF 是权威导出物;HTML 草稿预览允许,不能取代 PDF 编译);Figma 画板 `49:13389`(桌面)/`49:13603`(移动)。

## Global Constraints

- **后端写路径、作业、额度、渲染、PDF 导出、签名 URL 路由(`src/app/lessons/[id]/documents/[doc]/route.ts`)一律不改。** 唯一允许的后端改动:`src/lib/server/dal/lessons.ts` 新增一个**只读、按所有者过滤**的方法(见 Task 3),并同步更新 `tests/integration/ownership.test.ts` 里对 DAL 键集合的断言和越权测试(只加不减)。
- 预览、下载、标签页、HTML 草稿必须来自**同一个 `revisionId`**:所有链接显式带 `rev`;HTML 草稿用 `findRevision` 同样的规则(本人、未删除、`finalized`)取内容。
- **工作表(worksheet)的 HTML 草稿不得出现任何答案**:必须经 `documentView(pkg, "worksheet")`(类型上没有 solution 区),不得为 HTML 另写一套取数逻辑。
- **HTML 草稿必须带明确标注**:`Draft preview. The exported PDF is the final version.`(精确文案),并且**不取代 PDF**:`pdf-frame`、`open-pdf`、`download-pdf`、`document-tabs` 及其 href 全部原样保留,缺省视图仍是 PDF。
- KaTeX 安全配置固定:`trust: false`、`strict: "error"`、`throwOnError: true`、`maxExpand` 与 `maxSize` 设上限、`output: "htmlAndMathml"`;数学 TeX 只来自 `equationTex`/`operationText`/`solutionText`(由已校验的有理数与固定词汇生成),**不得**把课包里的任意文本当作 TeX 传入;KaTeX 抛错时回退为转义后的纯文本,页面不得 500。KaTeX 的输出是唯一允许进入 `dangerouslySetInnerHTML` 的内容,其余文字一律走 React 转义。
- KaTeX 样式与字体**本地打包**(`import "katex/dist/katex.min.css"`),不走 CDN。新依赖精确版本固定;按 CLAUDE.md §3 先查已装版本与官方文档,选择已发布至少两周的稳定版本,并在报告里写明版本与发布日期。

- 同一页面只有一个 `<h1>`、一个 `<main>`(由页面提供,layout 不输出);最多一个 `role="status"`;状态不只靠颜色;可点击控件 `min-h-11`。

## Review Focus

- HTML 草稿里的任何用户/模型可影响的文字(标题、段落、列表项、课程名、目标文字)都不能注入标记:恶意字符串如 `<script>alert(1)</script>`、`</p><img src=x onerror=…>`、`$\input{/etc/passwd}$` 必须被转义为文本,且不被当作 TeX → Task 2/4 的测试。
- HTML 草稿与 PDF 的内容一致:同一修订下,每份文档的题号、题目数、答案(解)的数量与 TeX 渲染一致 → Task 2 的一致性测试(用 `renderDocument` 的输出做对照)。
- 工作表草稿没有答案;解答草稿的每个答案都对应一个题目 ID → Task 2。
- 越权:别人的课包/别人的修订/已删除课包/非 finalized 修订通过新 DAL 方法都得到 `NotFound`;草稿视图的 URL 里手改 `rev` 不能看到别人的内容 → Task 3(单测 + 集成测试)。
- KaTeX 在服务端渲染且无客户端 JS 依赖;页面在 KaTeX 抛错时降级而不是 500 → Task 1/4。
